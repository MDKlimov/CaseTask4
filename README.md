# Сила драконьей стаи

## Условие задачи

Дано натуральное число `N` (`0 < N < 100`) — суммарное количество голов всех драконов в стае. У каждого дракона от 1 до 7 голов. Сила стаи равна произведению количества голов каждого дракона. Требуется найти **максимально возможную силу** при заданном `N`.

## Файлы

- `dragon_power.py` — программа на Python 3.
- `README.md` — описание алгоритма, доказательство и примеры.

## Запуск

Установите Python 3. Откройте терминал в папке с программой и выполните:

```bash
python dragon_power.py
```

Введите одно целое число, например `10`, и нажмите Enter. Программа выведет:

```text
36
```

Программа читает одно число из стандартного ввода и выводит только ответ. При вводе числа вне диапазона 1–99 возникает `ValueError`. По условию задачи предполагается корректный ввод.

## Алгоритм по шагам

1. Считать число `N`.
2. Если `N` равно 1, 2 или 3, вывести само `N` и завершить вычисление.
3. Найти целую часть `q = N // 3` и остаток `r = N % 3`.
4. Если `r == 0`, вывести `3 ** q`: все головы распределяются по тройкам.
5. Если `r == 1`, вывести `3 ** (q - 1) * 4`: вместо одной тройки и единицы использовать две двойки.
6. Если `r == 2`, вывести `3 ** q * 2`: добавить одну двойку к тройкам.

В Python оператор `**` означает возведение в степень, `//` — целочисленное деление, `%` — остаток от деления.

## Почему алгоритм правильный

- Дракон с 1 головой в стае из нескольких драконов невыгоден: 1 и любое число `a` можно объединить в `a + 1`, увеличив произведение (если `a < 7`); в оптимальном разбиении для `N >= 2` единицы не нужны.
- Число 5 выгоднее разбить на 3 и 2 (`6 > 5`), 6 — на 3 и 3 (`9 > 6`), 7 — на 3 и 4 (`12 > 7`). Число 4 эквивалентно двум двойкам (`4 = 2 * 2`). Следовательно, существует оптимальное разбиение только на двойки и тройки.
- Три двойки дают произведение 8, а две тройки при той же сумме дают 9. Поэтому в оптимальном разбиении не более двух двоек.
- Если остаток от деления N на 3 равен 0, двойки не нужны; если 1 — нужны две двойки; если 2 — одна двойка. Для N = 1, 2, 3 ответ равен N.

Это доказывает максимальность произведения, вычисляемого программой. Каждая группа содержит не более 3 голов, что удовлетворяет ограничению 7.

## Примеры

| Ввод N | Оптимальное распределение | Вывод |
|---:|---|---:|
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 3 | 3 | 3 |
| 4 | 2 + 2 | 4 |
| 5 | 3 + 2 | 6 |
| 7 | 3 + 2 + 2 | 12 |
| 10 | 3 + 3 + 2 + 2 | 36 |
| 11 | 3 + 3 + 3 + 2 | 54 |

## Оценка сложности

Алгоритм выполняет фиксированное количество арифметических операций: `O(1)` операций и `O(1)` дополнительных переменных при стандартной модели арифметики. При учёте разрядности больших целых чисел стоимость возведения в степень зависит от размера результата, однако для `N < 100` это несущественно.
